# Taloa!

Lección 2 de euskera, en pixel art y sin dependencias: pedís un talo en la feria, elegís los ingredientes y al final decidís lo de la mayonesa. Abrí `index.html`.

- `index.html`: el juego completo (HTML, CSS y JS).
- `assets/`: imágenes pixel art.

La lección 1 es [Mendira!](https://jtersoli.github.io/mendira/).
